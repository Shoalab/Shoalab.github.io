02

正交轴关节 · 机构设计

三大单元组 · 模块化可拆卸
正交关节单元示意 · 俯仰×偏航交替
UNIT GROUP 01
正交轴关节串联单元组
蛇身基本构建单元：仓体 O1 底部经微型电机 O7 联动双侧主动轮 O2，偏航舵机 O3 连接骨架 O4，俯仰舵机 O5 连接骨架 O6；骨架四角均布从动轮 O8 与销钉 O9。各件通孔轴线逐级重合装配、标准件固定，若干单元组串联成蛇身，每模块 2 自由度。
UNIT GROUP 02
连杆构件单元组
H 形连杆支架 C1 采用肋板加强设计，两端共 4 个舵机配合位（C1a1–C1a4）对应第一舵机 C2 与第二舵机 C3 的双侧配合盘；支架中部设穿线槽 C1c1–C1c5——既承担蛇身到平台的串联传力，又为电气控制线路预留走线通道。
UNIT GROUP 03
平台机械单元组
半包式长方体仓体 P1，孔位 P1a3 / P1a4 装配微型电机 P2 / P4，输出轴轴线重合联动左右主动轮 P3 / P5；平台自身亦为正交轴关节结构（舵机 P7 + 骨架 P8），可独立偏航调整。顶部装载可见光 + 红外热成像双模态相机。

03

工作状态 · 三态重构

同一本体 · 三种构型 · 覆盖行进 / 侦察 / 作业场景
FIG.16
STATE 01 · 常规行进
舒张式STRETCH
蛇身完全舒展的基础形态：主动轮 O2 驱动直线前行；转向蜿蜒时偏航舵机 O3 带动仓体与骨架水平摆动；遇障碍沟槽时俯仰舵机 O5 带动骨架 O4 / O6 竖向抬升，整机抬头跨越。
FIG.17
STATE 02 · 高位侦察
抬头式LOOKUP
连杆单元组双舵机 C2 / C3 偏航协同旋转，配合 H 形连杆支架 C1 将平台单元组 SR3 抬升至限定范围内的指定水平高度——相机获得高位俯瞰视野，越过废墟表层遮挡实施远距侦察。
FIG.18
STATE 03 · 原位作业
勾尾式HOOK-TAIL
双舵机将平台 SR3 旋转至蛇身后方相对方位形成"蝎尾"构型，第二舵机 C3 微调俯仰角，平台舵机 P7 + 骨架 P8 独立偏航对准目标——GEN2 仿蝎尾构造的机构原理即源于此，支撑原位在线检伤作业。
